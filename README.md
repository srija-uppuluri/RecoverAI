# RecoverAI

RecoverAI is an AI-powered payment recovery platform that helps merchants identify failed payments, checkout abandonment, failed subscriptions, and overdue invoices, and take recovery actions.

## Features

- Recovery case management
- Risk scoring for customers and transactions
- AI-powered recovery recommendations
- Recovery actions such as:
  - Retry Payment
  - Send Email
  - Send SMS
  - Apply Discount
  - Mark as Resolved
- Human approval for recovery actions
- Search and filter recovery cases
- Transaction and customer information
- Recovery activity and audit trail
- Dashboard and executive analytics
- SQLite database with Prisma

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- SQLite
